# FALSE//REAL

A 2D pixel-art puzzle-platformer about two worlds, one of which is lying.
Built with **Godot 4.7**.

Jam theme: **ILLUSION**.

---

## The illusion mechanic

Two worlds occupy the same space:

| | |
| --- | --- |
| **PERCEIVED** | Pale, bleached, white-hazed, uncannily still. Things exist here that do not exist anywhere else. |
| **TRUE** | Dim, grounded, grimy, believable. The world as it actually is. |

**`Q` really does move you between them.** It is not a filter, not a tint — the
collision, the geometry, the hazards and the enemies genuinely change.

The player is the same shape in both worlds. Only the tint changes.

> **The HUD is always truthful.**
> Reality indicator, objective, interaction prompt, checkpoint — all of it is honest.
> *Every* lie in this game lives in the environment: fake bridges, walls that are not
> there, doors that never existed, signs that say the opposite of the truth, and one
> beast that is two entirely different creatures depending on where you are standing.

By the end you should have learned: **what you see can be walked on, pressed, or walked
through — and it is not always there.**

## Setup

1. Godot **4.7** (stable) or newer.
2. Open the project folder. First launch imports ~94 PNGs; let it finish.
3. Press **F5**. The main scene is `res://ui/title_screen.tscn`.

No plugins, no external assets, no network access required. Everything — art and audio —
is generated by scripts in this repository (see *Credits*).

## Controls

| Action | Keys |
| --- | --- |
| Move | `A` `D` or `Left` `Right` |
| Jump | `Space` or `Up` |
| **Reality shift** | `Q` |
| Interact | `E` |
| Restart from checkpoint | `R` |
| Pause | `Escape` |

Stomp a crawler from above to hurt it. Touching one hurts you. The big ones take three.

## The run

| # | Area | What it is |
| --- | --- | --- |
| 1 | **AWAKENING** | Movement, a real gap, and the first shift past a wall that exists in only one world. No combat. |
| 2 | **THE FALSE PATH** | The illusionary bridge. A PERCEIVED-only platform filling a second gap. A fake wall whose passage is in TRUE. |
| 3 | **THE OTHER SIDE** | First checkpoint, first crawler. A crate that is really a floor plate. A door that opens onto nothing — and a passage that was always there. |
| 4 | **DISTORTION** | A ferry that only exists in one world, alternating PERCEIVED/TRUE platform runs, real spikes and fake spikes. |
| 5 | **THE LIE** | Lying signs, a **false objective delivered in-world**, and **ambiguous shifts** — see below. Plus the reality-dependent enemy. |
| 6 | **FALSE//REAL** | The gauntlet. Bridge, false object, false door, alternating platforms, a gate, and the beast — all at once. |
| — | **ENDING** | Quiet. Nothing is explained. |

### Area 5: ambiguous shifts

Inside marked zones, `Q` still performs a **real** shift — the world truly changes and
the HUD truly reports it — but the feedback is deliberately withheld: no glitch, no
camera shake, a whisper of a flash instead of a bang.

You have to work out where you are from the environment:

- **Solidity** — does the floor hold you?
- **The haze** — is the world bleached, or is it dim and real?
- **The enemy** — is it a tall slow drifter, or a small fast thing?
- **Sound** — a dull thud instead of the usual tear.

It is deterministic and scripted, never random. Getting it wrong is always your fault,
and always recoverable.

### The reality-dependent enemy (Puzzle 5)

One body, two completely different problems:

| | PERCEIVED | TRUE |
| --- | --- | --- |
| Form | Tall slow humanoid, drifting | Small fast creature, scuttling |
| Speed | 16 px/s | 62 px/s |
| Telegraph | **0.95 s** — long, obvious | **0.30 s** — short, sharp |
| Lunge | 118 px/s | 300 px/s |
| Warning colour | pale blue-white flare | hard cyan flash |

The player's form is easy to walk away from. Its true form will run you down. **Shift to
learn the real pattern.**

## Architecture

Puzzle logic is never scene-specific. Every piece is a small component that talks only to
`RealityManager` and `EventManager`; levels compose them.

| Component | Script | Behaviour |
| --- | --- | --- |
| `WorldLayer` | `scripts/world_layer.gd` | Shown **and** solid in exactly one reality. The backbone of every illusion. |
| `Platform` | `scripts/platform.gd` | Reality-gated platform, builds its own art + collision. |
| `MovingPlatform` | `scripts/moving_platform.gd` | Reality-gated moving platform that genuinely carries the player. |
| `Hazard` | `scripts/hazard.gd` | Lethal or knockback. Fake hazards simply have no `Hazard` on them. |
| `Interactable` | `levels/interactable.gd` | `E` to use; emits `mechanism_activated(id)` on the bus. |
| `Mechanism` | `scripts/mechanism.gd` | Listens for its own id, spins up, emits `mechanism_state_changed`. |
| `MechanismGate` | `scripts/mechanism_gate.gd` | Opens when its mechanism fires. |
| `Sign` | `scripts/sign.gd` | Text drawn **in the world** — so a lying sign can never make the HUD lie. |
| `AmbiguousShiftZone` | `scripts/ambiguous_shift.gd` | Requests a muffled shift via `EventManager.shift_style_requested`. |
| `Checkpoint` | `levels/checkpoint.gd` | Honest pylon. |
| `TutorialZone` | `levels/tutorial_zone.gd` | One quiet hint line while you stand inside. |
| `AreaExit` / `AreaRoot` | `levels/area_exit.gd`, `levels/area.gd` | Area flow, objective, camera framing, music. |
| `PatrolEnemy` | `enemies/patrol_enemy.gd` | Five-state crawler. |
| `RealityEnemy` | `enemies/reality_enemy.gd` | The two-form beast. |

**Autoloads:** `EventManager` (bus), `RealityManager` (which world, and how loudly to
switch), `GameState` (objective, pause, `AREA_SEQUENCE`), `CheckpointManager`,
`AudioManager`.

**Shaders:** `white_haze` (PERCEIVED), `dread` (always-on vignette/grain/breathing),
`glitch_chromatic` and `transition_flash` (shift feedback).

## Audio

No audio files ship with this build. `AudioManager` synthesises everything at startup:

- **SFX** — jump, land, shift, muffled shift, interact, switch, checkpoint, hurt, death,
  UI, glitch, enemy attack/hit/death.
- **Music** — three seamless 4-second drones on a dedicated `Music` bus carrying an
  `AudioEffectDistortion`. Per-area `music_distortion` opens it up as you get closer to
  the end, so the score comes apart alongside the world.

Replacing them is a one-function job: rewrite `_build_library()` to `load()` real
resources. **No caller changes.**

## Art

`res://tools/generate_placeholder_art.gd` draws all 94 assets at exact sizes with hard
pixels and no anti-aliasing (including a 3×5 pixel face used for the wordmark and the
whispered wall text). Re-run any time:

```gdscript
load("res://tools/generate_placeholder_art.gd").new().run()
```

Afterwards let Godot reimport (`godot --headless --import --path .`, or focus the editor).

## Notes for the next person

- `levels/test_room.tscn` is an older single-room sandbox. It still runs and is handy for
  poking at mechanics, but it is **not** part of `AREA_SEQUENCE`.
- Immediately after a `.gd` file is edited outside the editor you may see one
  `Compile Error: Identifier not found: <Autoload>` in the output. That is Godot's
  script-cache pre-pass compiling the changed file before autoloads are registered. The
  script compiles correctly when the scene actually loads; re-run and it is gone.
- Areas self-identify into `AREA_SEQUENCE` by their own path, so running any area
  standalone still hands off to the correct next one.
